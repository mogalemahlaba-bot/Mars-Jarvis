Google Drive connection & system config.

GOOGLE DRIVE SYNC

Create one free in Google Cloud Console (OAuth Client ID → Web application), add this page's URL as an authorized JavaScript origin, and enable these APIs in the same project: Drive API, Google Calendar API, Gmail API, and People API. This is required because Jarvis has no backend — your data lives only in jarvis-data.json in your own Drive, and calendar/email/contacts are read live from your account each time.
Not connected.

VOICE & SYSTEM

All notes, tasks, settings and conversation history sync to a single jarvis-data.json file in your Google Drive's app folder. No other backend or database is used.

AI CAPABILITIES

Get a free key at console.anthropic.com. Since Jarvis has no backend, this key is stored only in this browser's local storage on this device — it is not synced to Drive or shared anywhere. Set a low spending limit on the key as a safety net, and don't share this app's link publicly while a key is set.

HOW IT'S USED

When a voice or typed command doesn't match a built-in Notes/Tasks/Contacts command, Jarvis sends it to Claude (Haiku model) and speaks back the reply. Without a key set, Jarvis just says it doesn't have a command for that yet.
